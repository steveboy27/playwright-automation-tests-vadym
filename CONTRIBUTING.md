# Contributing

1. Open an issue describing the application behavior and expected result.
2. Add or update a scenario in `specs/saucedemo-regression.md`.
3. Add a focused test with meaningful assertions and independent data.
4. Run `npm run check` and relevant Playwright tests.
5. Include a screenshot or trace only if it contains no sensitive information.
6. When using AI, add the prompt or summary of how generated code was reviewed.

Use focused commits such as `test(cart): verify item persistence after navigation`.
